# 铁路列车运行图编辑器

基于 Angular、PrimeNG、NgRx 和 Canvas 的列车运行图编辑工具。提供运行线缩放平移、拖动调整、停站/通过设置、追踪间隔与到发线冲突检查、批量平移、**区间施工（临时限速）计划登记与容量互斥排队**、JSON 数据导入和区间打印。

## 施工计划

- 每份计划登记区间、方向（上行/下行）、起止时刻与限速值（km/h），可附施工内容说明。
- **同一区间、同一方向、同一时段只允许 1 份计划生效**；超出容量的计划自动排队，并在登记窗口列出与它互斥的生效计划及时段。
- 生效计划时段内，按该方向进入区间的列车若排点旅行速度高于限速，立即生成“施工限速”冲突，指出受影响车次与对应计划；已按限速排点的列车给出关注提示。
- 运行线（拖动、平移、停站改点）或施工计划任意变化时，只失效并重算受影响的冲突记录，未受影响记录保持不变；计划变动不会重算列车间记录，反之亦然。
- 旧版数据缺少 `constructionPlans` 字段时按空计划继续使用；导出 JSON 与冲突分析 CSV 均带上计划。
- 区间打印件在图头列出当前施工限制（生效/排队、时间窗、方向、限速），图面对应时段绘制施工控制带。
